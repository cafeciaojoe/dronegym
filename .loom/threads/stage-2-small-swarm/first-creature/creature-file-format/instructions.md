# creature-file-format

A creature in a file: body, behaviour, sensing, provenance. Versioned from the first write.

This is the artefact the brief's headline rests on — put the creature in a sim, change it, pull it
out. It is also what Stage 3 will extend, so getting the boundary roughly right now is worth more
than getting it complete.

## Done when
- [ ] Versioned schema: nodes, connections, parameters, sensing config, name, provenance
- [ ] Load and save round-trip test
- [ ] One creature loads into the room runtime and a headless run unchanged
- [ ] `docs/creature-format.md` written
- [ ] `DECISIONS.md`: what is in the file, and what is deliberately left out for now
