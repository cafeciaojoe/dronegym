# multi-drone-link

N drones through the link, at the rate the radio budget (0.3.1) says is safe.

## Done when
- [ ] N drones commanded independently at the measured safe rate
- [ ] Per-drone link health surfaced, not aggregated into one number
- [ ] Behaviour checked at N and at N+1, so you know where the edge is
- [ ] `docs/drone-link.md` written or updated — what it does, how to run it
- [ ] `DECISIONS.md` entry if a choice was made — what we picked, what we rejected, why
