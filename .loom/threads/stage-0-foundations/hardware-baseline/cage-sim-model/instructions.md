# cage-sim-model

Low-poly model of the spherical cage, loaded into the sim. Because the cage is a sphere, the virtual
body and the physical body are the same shape — the sim sphere is not a metaphor.

## Done when
- [ ] Low-poly cage exported and loading in MuJoCo
- [ ] Mass and dimensions match the printed cage as measured, not as designed
- [ ] Collision geometry kept separate from visual geometry
- [ ] `docs/cage-model.md` written or updated — what it does, how to run it
- [ ] `DECISIONS.md` entry if a choice was made — what we picked, what we rejected, why
