# dg-doctor

One command that checks the setup and says what is broken before you lose an hour to it. Same
convention as `brew doctor`.

## Done when
- [ ] Checks radio present, lighthouse geometry loaded and dated, battery levels, firmware versions
- [ ] Prints a red/green checklist and exits non-zero on any failure
- [ ] Runs with no drones powered on — reports them missing rather than hanging
- [ ] `docs/dg-doctor.md` written or updated — what it does, how to run it
- [ ] `DECISIONS.md` entry if a choice was made — what we picked, what we rejected, why
