# endurance-run

Ten minutes of continuous interaction, no divergence, no intervention.

Also the covered-sensor test with a person in the loop: the user unknowingly covers the handheld's
deck. Jump rejection should catch it within one sample, the timer catches the sustained case, and the
operator sees the freeze and can prompt them back into coverage. Test the freeze AND the recovery —
the recovery is the part that used to be a punch.
