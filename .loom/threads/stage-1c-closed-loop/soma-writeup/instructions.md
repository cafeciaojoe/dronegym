# soma-writeup

Does it feel like pushing something? Written up first-person.

This is a soma design project. "Responsiveness and stability" is not only a plot — the felt quality of
the interaction is the actual result of Stage 1, and if it is not written down while it is fresh it
is gone.

- [ ] At least one other person interacts and writes their own account
- [ ] What to change next, named — feeding back into coupling tuning
- [ ] `docs/soma-1c.md` written
