# backfeed-ringing-test

Command a step and check the sim/drone pair settles rather than ringing. Then find the loop delay at
which it starts to oscillate, so you know how much margin you have.

## Done when
- [ ] Step response of the coupled pair captured
- [ ] Settles rather than ringing at the measured loop delay
- [ ] Delay at which ringing starts, found by injecting artificial delay
- [ ] `docs/backfeed.md` written or updated — what it does, how to run it
- [ ] `DECISIONS.md` entry if a choice was made — what we picked, what we rejected, why
