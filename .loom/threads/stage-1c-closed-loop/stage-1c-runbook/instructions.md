# stage-1c-runbook

What makes Stage 1c shippable. This is the first configuration that could genuinely run a workshop,
so treat the run-book as the deliverable it is.

## Done when
- [ ] One-page run-book: bring-up, session, abort, shutdown
- [ ] Facilitation notes: what to tell a user, what to watch for, when to intervene
- [ ] Someone who is not Joseph runs a full session with a real user, from the run-book alone
- [ ] `docs/runbook-stage-1c.md` written or updated — what it does, how to run it
- [ ] `DECISIONS.md` entry if a choice was made — what we picked, what we rejected, why
